# Vrinda Store Excel Data Analysis

## 📌 Project Overview

Vrinda Store Excel Data Analysis is a sales data analysis project created using Microsoft Excel. The project focuses on analyzing sales performance, customer demographics, order status, sales channels, and product categories through Pivot Tables, Pivot Charts, slicers, and an interactive dashboard.

## 🎯 Business Objective

The main objective of this project is to transform raw sales data into meaningful insights that can help understand:

- Overall sales performance
- Monthly sales trends
- Customer demographics
- Order status distribution
- Sales performance by channel
- Sales performance across states
- Product category and quantity trends

## 🛠️ Tools & Techniques Used

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
- Interactive Dashboard

## 📊 Dataset

The dataset contains sales transaction records with information such as:

- Order ID
- Customer ID
- Gender
- Age
- Age Group
- Date
- Month
- Order Status
- Sales Channel
- Category
- Size
- Quantity
- Amount
- Shipping State

## 🧹 Data Preparation

The raw data was checked and prepared before analysis. Key preparation steps included:

- Cleaning inconsistent values
- Standardizing Age Groups
- Checking date values
- Verifying customer IDs
- Checking sales amount and quantity values
- Creating month-based analysis
- Preparing data for Pivot Tables and Charts

## 📈 Analysis & Dashboard

The Excel dashboard provides an interactive view of the sales data using:

- Month slicer
- Channel slicer
- Total Sales KPI
- Total Orders KPI
- Total Quantity KPI
- Average Order Value KPI
- Orders vs Sales analysis
- Men vs Women analysis
- Order Status analysis
- Top 5 States analysis
- Age & Gender analysis
- Sales Channel analysis

## 💡 Key Insights

The dashboard helps identify patterns and comparisons in:

- Monthly sales performance
- Customer gender and age distribution
- Order status
- Sales channels
- State-wise sales performance
- Product quantity and category performance
